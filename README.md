# Dasom Kim (김다솜)

## About Me
Java/Spring을 주력으로, JSP 기반 레거시 스택부터 NestJS, Next.js 기반 최신 스택까지 다뤄온 **6년차 백엔드 개발자**입니다. 
골프 예약 플랫폼(티스캐너, 골프존카운티)을 리뉴얼하고 운영하며, 예약·결제·외부 연동까지 서비스 전 영역을 화면-서버-DB로 연결해 개발·배포해왔습니다.
- 트래픽 부하와 장애의 근본 원인을 데이터 기반으로 추적하고, 흩어진 레거시 구조를 정리해왔습니다.
- 반복되는 비효율을 줄이기 위해 업무 지시 없이 사내 자동화 봇(Discord)을 기획, 개발해 팀 전체에 배포한 경험이 있습니다.
